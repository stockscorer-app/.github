# StockScorer

StockScorer scores stocks against rules you define yourself and shows, for every stock, which conditions it meets.

StockScorer is a tool for private investors who want to check stocks against fixed rules. Build your own rule set from fundamental metrics or start from one of 18 published profiles such as the Piotroski F-Score. About 16,000 stocks are recalculated every night, every rule is visible, and every profile can be backtested. There is a guest mode without an account and a free plan with no time limit.
